# 🎓 AI Course Curriculum Generator

An AI-powered system that automatically generates structured and personalized **course curricula based on learning objectives**. The system helps educators and learners create relevant topics, modules, learning outcomes, and course structures quickly.

## 👨‍💻 Author

**D Pranay Reddy**

## 📌 Project Description

The **AI Course Curriculum Generator** uses Artificial Intelligence to transform learning objectives into a complete course curriculum.

Users provide learning objectives, subject details, skill level, and course duration. The system generates a structured curriculum containing modules, topics, learning outcomes, and suggested activities.

## 🎯 Objectives

* Generate course curricula automatically using AI.
* Convert learning objectives into relevant topics and modules.
* Save time in curriculum planning.
* Create structured and easy-to-follow learning paths.
* Support different skill levels and course durations.
* Improve personalized learning experiences.

## ✨ Key Features

* 📝 Learning objective input
* 🤖 AI-based curriculum generation
* 📚 Automatic module and topic creation
* 🎯 Learning outcomes for each module
* 👨‍🎓 Beginner, Intermediate, and Advanced levels
* ⏱️ Course duration-based planning
* 📋 Structured curriculum output
* 💡 Suggested projects and activities
* 📱 Simple and user-friendly interface
